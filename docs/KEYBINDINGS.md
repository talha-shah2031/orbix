# Keyboard bindings

The TUI contains one tab: **Spot Market**. The market list is filtered by the selected quote token and sorted by 24-hour base-asset volume.

| Key | Action |
|---|---|
| `1` | Return to Spot Market |
| `q` / `Q` | Cycle USDT, BTC, USDC, and ETH quote pairs |
| `[` / `]` | Previous / next 100-pair volume range |
| `j` / `k` | Scroll rows in compact grid mode |
| `/` | Search the displayed Spot pairs |
| `Esc` | Clear the search filter |
| `t` | Cycle dark, light, high-contrast, and colorblind-safe themes |
| `r` | Refresh market data |
| `Ctrl+C` / `Ctrl+Q` | Quit |
