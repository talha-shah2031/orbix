# Keyboard bindings

Bindings are shared across views unless a view has a focused search field.

| Key | Action |
|---|---|
| `1`–`8` | Dashboard, Markets, Symbol, Futures, Account, Alerts, Diagnostics, Help |
| `9` | Spot Market heatmap |
| `j` / `k`, arrows | Move through market rows |
| `g` / `G` | First / last market row |
| `/` | Search symbols and assets |
| `s` | Cycle sort order |
| `f` | Favorite the selected market |
| `F` | Show or hide favorites only |
| `Q` | Cycle quote asset filter |
| `Enter` | Open selected symbol detail |
| `Esc` | Return to the previous view or clear search |
| `[` / `]` | Change candle interval |
| `+` / `-` | Zoom symbol chart |
| `m` | Cycle Spot, USDⓈ-M, COIN-M, and Options |
| `t` | Cycle dark, light, high-contrast, and colorblind-safe themes |
| `r` | Refresh market data |
| `:` / `Ctrl+P` | Open the searchable command and symbol palette |
| `?` | Show this key reference in-app |
| `q` / `Ctrl+C` | Quit |

Favorite/watchlist changes are stored locally by profile. Theme selection remains session-only.
